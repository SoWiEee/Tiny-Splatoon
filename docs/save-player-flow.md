# 保存與玩家流程

原生入口使用標題、首頁、遊玩、裝備、角色置物櫃、設定、操作說明與製作名單。簡約 RmlUi 版面保留 Inter／Noto Sans TC，品牌為 Tiny Splatoon。裝備、地圖與外觀採繁中名稱；自訂名稱與官方術語的區別見 [翻譯表](ui-translations.md)。來源對齊 `spec.md` 的 SAVE-01–05、FLOW-01–05／09–10；尚未完成的後端不得因欄位存在而視為已移植。

## 保存契約

- `%LOCALAPPDATA%/Tiny-Splatoon/profile.json` 保存玩家名稱、裝備 ID、外觀索引、等級、XP、勝場、場次、累積塗地及設定。
- 缺檔或無效 JSON 使用安全預設；舊武器別名轉為現行 ID，未知欄位不影響讀取。UTF-8 名稱限制為 16 個字元。
- 先寫入暫存檔，再原子替換正式檔。讀寫權限錯誤呈現在 UI；替換失敗保留舊檔。
- 完整結束的離線對戰結算一次；中途離場與練習不給 XP。保存最近一次結算 ID，避免同一結果再次套用。這不是歷史賽事重播帳本。
- XP 基礎獎勵為勝利 1200／失敗 500、每次擊倒 40；塗地計分、Boss 傷害與 Zones 額外分依來源公式。Zones 公式單元測試通過不代表模式已可玩。

## 玩家流程

3D 角色預覽與裝備／外觀同步；結果顯示四人隊伍、勝負姿勢與 XP。離開尚未結束的對戰前顯示確認。練習無計時、無 Bot，提供清除墨水、補滿、回出生點、換圖及 L 換裝入口，練習不寫入對戰成績。

音量立即套用，渲染品質下一場套用。支援全螢幕、幀率上限、FOV、攝影機晃動、滑鼠／手把靈敏度、瞄準輔助、色盤、色覺輔助與原生小地圖。手把採 GLFW gamepad mapping；目前尚未接入觸控與震動後端，相關控制項停用。線上入口清楚標示尚未提供。

## 驗證

`native_player_profile` 檢查重開、UTF-8、損壞資料、舊 ID、多級升等、重複結算與寫入失敗保護；`native_player_controller` 檢查視角／死區／輔助；`native_player_showcase` 實際繪製角色並檢查外觀與 GL 狀態；`native_team_palette` 檢查色盤；`native_ui_translations` 檢查完整名稱表。既有 `reference_player_ui_interactions` 測試涵蓋設定往返、練習、離場確認、小地圖與結果。

實體手把手感、震動與觸控尚未驗收。本輪不代表線上、Zones 或全遊戲視覺對照完成，來源資料夾繼續保留。
