## 移除 splat-ref 的完成門檻（2026-10-21 核對）

一般建置、遊戲執行與 Windows 發布已使用提交於 `src/`、`assets/` 的原生程式及資產，不需要 `splat-ref/`、瀏覽器或 Node.js。這代表執行環境已獨立，並不代表原版全部功能已移植。

建議依以下順序完成剩餘遷移：

1. **原生測試獨立及保存／玩家流程**：把 LOD 來源期望值固定成有來源 hash 的 fixture；World FX 的原生 fixture 比對與可選來源 hash 驗證分開。目前 `reference_character_lod` 與 `reference_worldfx_oracle` 在 CMake 的來源存在條件之外註冊，卻直接讀取來源檔，不能以刪除或停用測試代替移植。接著完成設定／profile／裝備／外觀／XP 保存、Locker／預覽及玩家入口往返。
2. **Zones 與正式結算**：規則、AI、HUD、音效、延長與 XP 結算整合，保留可重現測試資料。
3. **剩餘美術／音訊接點及完整單人驗收**：裝置次級動作、Boss hazard／live crablet、投射物細節及音訊 socket。Boss 主體姿勢已通過 16/16 嚴格 oracle，見 [目前姿勢契約](boss-pose-source-contract.md)；早期 0/16 紀錄只是歷史檢查點。
4. **原生多人連線**：以 GameNetworkingSockets 完成房間、同步、斷線／換主／Bot 接手與三模式跨網矩陣。僅保留套件依賴不算完成。
5. **最終獨立驗收及來源退役**：在沒有 `splat-ref/` 的乾淨 checkout 建置、執行全部原生回歸與完整玩家流程，檢查各畫質及最壞負載。來源專用匯出器／瀏覽器比對工具可在退役時封存或移除，但需先保留固定 fixtures、資產、來源 hash、授權及必要的比對證據；不能讓缺少來源資料夾默默變成「完整還原通過」。

完成上述來源比對前，保留鎖定的參考版；退役後專案內不再要求這個目錄。此核對未刪除或改動 `splat-ref/`。
