# Device and special lifecycle audit

This is a source-to-native inspection matrix for the 15 subweapons and 19 specials registered in `src/game/ArsenalData.cpp:1195-1235`. Source links point into immutable `splat-ref`; no source or baseline file was changed. A test named in the last column covers the stated CPU behavior. The device GPU fixture loads every model/team record, but it is not a test of every lifecycle phase. Rows without a named lifecycle test are code-inspection results only.

The shared native device lifecycle is `CombatWorld::deploy` → `updateDevices` → `explodeDevice`, with ray/area damage at `blockRay`/`damageDevices`; `DeviceRenderer::Update` and `Draw` present the snapshots, while `WorldEffects` consumes visual events. The shared special lifecycle is `WorldSpecials::activate`, `body`/`weapon`/`tickActor`, and `tickWorld`; `WorldSpecials::visualObjects` supplies persistent objects to the renderer. Links: [CombatWorld.cpp](../../src/game/CombatWorld.cpp#L133), [WorldSpecials.cpp](../../src/game/WorldSpecials.cpp#L44), [DeviceRenderer.cpp](../../src/render/DeviceRenderer.cpp#L182), [WorldEffects.cpp](../../src/render/WorldEffects.cpp#L303).

## Acceptance boundary

`tests/combat_device_test.cpp` now adds targeted boomerang contact/fuse and ray-destroy event checks; `tests/world_specials_test.cpp` checks the Bomb Rush throw event for every accepted first and follow-up throw across all five variants. These tests were added in this audit slice; final build/test status must come from the shared integrated acceptance run. The earlier device model GPU fixture covers source models and tracer-tail lifecycle, and the current source-driven world-FX fixtures cover only their listed recipes. None of these checks certifies every item/device/special warning, active, impact, and cleanup frame. Remaining known approximation boundaries are the source-specific generic fly spin, deterministic cloud puff placement, unverified full hand-charge visuals, and untested full lifecycle renders called out in the rows above.
