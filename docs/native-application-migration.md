# Native application entry migration

`--native` enters the restoration stage-select screen and starts an offline Turf match in the same GLFW window and ImGui context. The screen lists offline Turf stages; the match uses the existing `MatchSimulation`, `StageRenderer`, `CharacterArt`, and `FollowCamera`. Returning from pause or the results screen destroys that match's stage, paint, simulation, pose, and renderer objects while the OpenGL context is still current, then reopens stage select. Results show the winner and final coverage and offer stage select/replay or close. Closing from the stage select, pause, or results screen closes the window. `--native --frames N` is a bounded menu smoke path; after drawing N menu frames it prints a `NATIVE_MENU state=stage-select` record and exits.

`--reference-match [stage]` starts the same local-player match directly. WASD or the arrow keys move relative to the camera, mouse motion aims, left click fires, right click or E uses the sub weapon, Shift squid-swims, Space jumps, F or Q activates the special, C cheers, and Escape pauses or resumes. The pause screen can return to stage select in `--native` mode or close a directly launched match. Losing window focus pauses the match. Mouse capture resets its cursor baseline and blocks held fire until release, so opening or resuming a match does not turn a held click into a shot.

The ordinary match path follows the local actor with `FollowCamera` and shows the match clock, team coverage, local HP, ink, special charge, and respawn state. Strike-style map-target specials follow the mouse aim point and confirm with a click after the simulation's ready delay. The existing simulation owns combat, bot control, respawning, judging, and coverage. StageViewer only translates GLFW input into `PlayerInput` and draws the current camera and HUD. Focus loss pauses play; resume synchronizes held sub/special inputs and requires fire release after cursor capture.

The `--benchmark-report` path remains separate inside `MatchLoop`: it keeps the scripted local input, fixed overview camera, fixed 60 Hz simulation, hidden 1920×1080 window, fixed warmup/sample frame counts, and skips ImGui. This path is intended for deterministic performance capture; interactive controls, menu frames, and HUD draws are not added to its measurements. `--native` rejects reference match/game entry, probe flags, capture options, and benchmark options during argument parsing before GLFW initialization; `--frames` is reserved for the menu smoke run.

This is a native playable entry slice. The menu currently selects offline Turf stages; it does not provide the complete reference hub, locker, settings, results, weapon selection, online lobby, or controller/touch flows. Match rendering still lacks several combat effects and final post-processing. The legacy application remains the default entry while this path is validated.

Remove the legacy application path only after the native entry owns the required player-facing menus and lifecycle across the supported modes, the restoration UI and rendering gaps have acceptance evidence against the reference, and startup, practice, match, pause/return, and diagnostic CLI behavior have all been checked. Keep stage, paint, play, and deterministic benchmark probes available as development tools after that transition.
