# Native environment source contract

The native environment is built from the locked `splat-ref/src/world/environment.js` source, SHA-256 `c359eeef59c83a9937ebf14e18a2d2711e59a17f6af97484af836cf9779c6bb5`. Its three themes supply the original sun direction, sun/hemisphere strengths, fog, sky/sea colors, haze, and water settings. The native renderer receives the selected stage's theme and water mode; Halyard and Lockgate use the marina path, while the other maps use open sea.

`tools/export-environment-source.mjs` expands the source sky and sea shader templates into desktop GLSL and exports theme values, the source sphere and polar sea geometry. The source sun disk, baked cloud lookup and drift, cirrus, sky gradient, swell, wave normals, water shading, Fresnel reflection, glints, foam and haze stay in the shader path. Three.js shader includes are expanded for the native GLSL program, and the native sea binds the source directional shadow map. The arena's oriented deck and wet-hull rectangles, foam distance field, and far scenery are exported per map by `tools/export-environment-scene.mjs`, which evaluates the unmodified source environment builder with each Turf layout. It builds source PropKit dressing into the scene before the level and environment, as `main.js` does, so waterline contours include real piles, fenders, ladders, and boats. The exporter records 13,750 PropKit water contour segments for Halyard and 680 for Lockgate and fails if a marina map has none. Its scene packs contain source meshes, materials, instance transforms, and motion parameters for sailboats, buoys, gulls, moored boats, the ferris wheel, and lighthouse beam.

`tools/export-environment-textures.mjs` captures the source GPU cloud bake and PMREM target for day, sunset, and golden themes, plus the CPU-generated periodic wave texture. Each compressed texture contains a `TSENV001` header with width, height, and bit depth followed by bottom-up RGBA pixels. Cloud targets are 2048×640 RGBA16F, Three.js PMREM cube-UV atlases are 768×1024 RGBA16F, and the wave texture is 256×256 RGBA8. `assets/reference/environment/textures.json` records each raw payload hash. The desktop runtime reads these files; it does not need a browser.

`EnvironmentRenderer` draws the sky, water, and exported scenery and supplies the source light state to stage, character, projectile, device, and boss renderers. It renders a planar mirror pass for marina water and bakes a far-scenery cubemap. Source fog and PMREM values flow through the common scene lighting contract. The reflection pass uses a water-plane oblique clip, and the distant scenery is omitted from the planar pass because its cubemap supplies that contribution.

The focused GPU test `reference_environment_gpu` renders all eight map variants. It checks nonblank sky/sea/scenery output, theme light state, marina reflection work, and visible motion after 2.5 seconds. The initial integrated run reported 292,688 changed pixels across the eight maps on an NVIDIA GTX 1650; that run preceded the PropKit water-contour export correction. This is a motion and coverage check, not whole-frame pixel parity with the browser source. The full game capture and performance checks remain part of the final integration pass.

Run source and GPU checks from the repository root:

```powershell
node tools/export-environment-source.mjs --check
node tools/export-environment-scene.mjs --check
node tools/export-environment-textures.mjs --check
ctest --test-dir build -R reference_environment_gpu --output-on-failure
```

The browser texture check recaptures the actual source render targets and compares all seven files byte for byte. A prior day capture differed from a fresh one by 18,062 of 5,242,880 cloud half-float values and 773 of 3,145,728 PMREM values; the wave, sunset, and golden assets matched exactly. Repeated Intel Iris Xe / ANGLE D3D11 captures, including a second day bake after theme switches, were identical to each other. The day assets were regenerated from that reproducible source capture, and `--check` passes on the same GPU. Cross-GPU bitwise reproducibility has not been established; a failure on another driver needs inspection of the reported texel differences and renderer identity before replacing assets.

The final integrated source fixture passes all eight maps, with 287,046 changed motion pixels on GTX 1650. Saltpan has 55 deck rectangles and uses the original `_bakeDeckField` shader to produce a native RGBA16F distance texture; no rectangles are dropped. Shader/material keys include serialized uniform defaults as well as expanded GLSL, preserving per-material parameters. A source-mode footprint probe found identical underwater footprint transforms/counts between the legal Turf/Zone/Boss variants of each map (44/29/16/55/10/22/48/29 across the eight maps), so the shared environmental footprint does not require duplicate mode assets. Mode gameplay and full-frame pixel parity remain separate acceptance items.
