# Boss material source contract

`tools/export-boss-materials.mjs` builds the six renderer materials (`steel`, `cara`, `flesh`, `eye`, `junk`, and `crablet`) from `splat-ref/src/boss/bossMats.js`. It uses the same `buildSourceMaterialShader` path as the character shader exporter and saves each pair of GLSL sources, numeric material defaults, and a manifest with source hashes and shader digests under `assets/reference/boss/shaders/`. The exporter captures `makeStencilTexture()` in a real browser canvas after its source fonts load; `stencil.tex.z` stores the bottom-up RGBA8 pixels in the stage-texture `TSTEX001` format. Run `node tools/export-boss-materials.mjs --check` to verify the committed outputs.

The Boss model binary uses `IBOS` version 2. Each vertex stores position and normal as three Float32 values apiece, source UV as two Float32 values, four Uint8 joint indices, then four Float32 weights and four Float32 material (`aM`) values. The vertex record is 68 bytes. `tools/export-boss-model.mjs --check` verifies that the binary and manifest match the locked source. Preserving UV matters because the source fragment shader uses it for stencil, wear, drips and other material effects.

`BossRenderer` compiles these source shader pairs through `CharacterShader`, binds the source stencil atlas and the physical DFG lookup texture, supplies the source UV and skin attributes, and uploads `BossPose::materialUniforms()` for each mesh draw. This keeps flash, phase, weak-point, crack, eye, container, and other pose-driven material state on the production render path. The native renderer currently supplies its existing local ambient, directional and hemisphere light values. Sharing the exact source theme lighting and environment map across every scene renderer remains part of the environment/lighting backlog.

`tests/boss_material_gpu_test.cpp` starts a legal offline Boss match, advances the normal match and pose sink to its visible intro, renders the production `BossRenderer::Draw` path, applies a real accepted Boss hit, updates the renderer through the same pose sink, and verifies that the live flash uniform changes visible pixels. CTest registers it as `reference_boss_material_gpu`; this is a GPU check of shader compilation, source mesh drawing, stencil/DFG bindings and a dynamic material response, not an image-wide reference comparison.
