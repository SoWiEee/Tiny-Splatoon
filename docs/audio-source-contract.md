# Native audio source contract

The native audio bank is exported from the source procedural engine. `tools/export-audio-source.mjs` imports `splat-ref/src/audio/audio.js`, then `splat-ref/src/game/kits/index.js` so every kit registers its sounds, and renders every registered SFX through Microsoft Edge's `OfflineAudioContext`. The same exporter renders all nine arrangements in `splat-ref/src/audio/music.js`, including each track's intro and one complete arrangement. The generated music is encoded as lossless 48 kHz stereo FLAC; its manifest stores the `loopFrom` frame and the arrangement end frame so playback starts with the intro and repeats at the source loop point.

SFX cues and loop beds are source-rendered at 48 kHz, stereo PCM16, seed 1234, with the source master processing enabled. One-shot renders retain 120 ms after the last sample above −60 dBFS. Loop renders remove the opening fade and blend the end seam. The manifest records source voice caps, pitch jitter, minimum repeat gaps, loopability, measured levels, hashes and durations. `--check` keeps the eight-LSB per-sample comparison for SFX and loop beds, then checks each music file's exact frame count and compares the full master-processed waveform using three bounds: at most 1,024 PCM16 LSB maximum difference, full-scale normalized RMS error at most 0.003, and Pearson correlation at least 0.9999. It also verifies exact track order, BPM, loop frames, asset hashes and formats, decoded music PCM hashes and asset file set. To keep the manifest replay stable when Edge's compressor shifts a loop's measured active duration or level, `--check` ignores only the loop `sourceActiveSeconds`, `sourcePeak` and `sourceRms` values; loop WAV hashes, sizes, formats and frame counts remain exact. An existing loop WAV within the eight-LSB source comparison remains canonical for both export and check, so its manifest hash matches the packaged asset. The wider music bounds account for measured variability in Edge's final Web Audio compressor stages, which is larger on some otherwise equivalent offline renders. Two fresh full-length 2,969,280-frame `battle` renders with the same source code and seed measured max differences of 28 and 616 PCM16 LSB; the latter pair had 0.002252 normalized RMS error and 0.9999306766 correlation. Comparing the checked-in lossless FLAC to that fresh render measured 616 LSB maximum, 0.002252 normalized RMS error and 0.9999306770 correlation. The retained bounds cover that measured spread with headroom. A synthetic one-frame circular shift of the source waveform is rejected (12,818-LSB maximum, 0.03321 normalized RMS error and 0.9935958 correlation), leaving a wide margin from the acceptance envelope. These measurements describe browser-render stability and do not claim sample-identical browser synthesis. The runner uses Edge's DevTools protocol and Node's built-in WebSocket without adding an npm dependency; set `EDGE_PATH` or `FFMPEG_PATH` when those programs are outside `PATH`. The exporter check and `tests/audio_source_render.test.mjs` require `ffmpeg` to decode the nine FLAC tracks; the native runtime uses miniaudio and has no ffmpeg dependency.

`restoration::AudioEngine` reads its cue list and source metadata from `assets/audio/catalog.tsv`. It keeps 48 bounded one-shot voices and 24 bounded loop voices, enforces each source cue's repeat gap and per-name cap, applies source pitch jitter, and supports pitch, 3D position, listener orientation, loop updates, fades, master/music/SFX buses, music ducking and crossfades. Source one-shots and loop beds are cached as PCM; voices own independent miniaudio cursors while borrowing the cached sample data. The nine music tracks stream from FLAC, use the source arrangement loop points, and share the same music bus. `Clear()` stops all active voices; `GameAudio::EndMatch()` fades managed loops and music out so scene changes do not leave audio running.

`restoration::GameAudio` routes the native actor triggers and state changes, match phase, `WorldVisualEvent`, boss move/phase, boss hit, and crablet transitions to source SFX and soundtrack tracks. The current gameplay routing is:

The audio-only event kinds are retained for `GameAudio` and skipped by world-particle recipes. Warning and destruction events carry source ID, position and team; charge is used only where the source sound varies with fuse progress or Waddle's flight/armed phase. Event coverage does not imply exact WebAudio playback equality.

Boss move sounds use the source-authored named socket positions from the same fixed-step animated rig used by combat. These 20 audio/effect sockets are stored separately from the original 10 combat hit shapes; a missing name falls back to the boss body position. Barrel cues retain their exact simulation-provided positions. Except for the continuous Zones hum, source-specific loop `params` are not exposed by native simulation events; managed loops use their source-rendered default timbre with runtime volume, pitch and position updates.

Live ZoneHum now splits into a dry spatialized branch and a shared, nonspatial stereo plaza reverb return. The source 1.5 s/decay 3.4/seed 3 impulse, 12 ms predelay, normalization and return 0.6 are reproduced. Its base send is captured at voice creation as `0.12 + min(0.45, max(0, (distance-4)*0.025))`; subsequent distance changes apply the source send scale to that stored value. Packaged SFX/loop beds already contain source processing and are not reverberated a second time. The live music riser adds the source 2.2 s/decay 2.4/seed 5 impulse with send 0.25 and return 0.5 before native compression, retaining the tail across the bar transition. This convolution check does not claim identical browser compression or HRTF spatialization.

The independent 48 kHz Web Audio impulse/convolver fixtures, source hashes and regeneration command are recorded in [the reverb fixture contract](../tests/fixtures/audio-reverb-source.md). `reference_native_reverb` compares raw impulses within 1e-7 and wet samples within 3e-6 without timing shifts; it exercises dry/wet splitting, 256/480-frame graph quanta, irregular reads, zero sends, non-finite input and reset/teardown. Audio callbacks allocate no FFT buffers or plans.

Boss socket placement follows the source-authored 20-socket rig at each fixed simulation pose. Native Boss audio now schedules the intro roar and slam 350 ms and 100 ms after the detected intro pose, delays the Slam cue by 120 ms, delays Charge's roar by 200 ms, staggers 3–5 Barrage whistles every 200 ms with barrels beginning at 950 ms, and plays a second Crablet chitter 300 ms after the first. The native simulation does not deliver the source claw `boss:impact` event, so the delayed Slam cannot be cancelled or aligned to the exact animation impact. Barrage pitch variation uses the native audio random stream rather than the source's global `Math.random`; native gameplay creates 4/5/7 barrels by phase while the audio sequence selects 3–5, and unmatched barrel cues keep the source's unpositioned 0.55-volume fallback. Result XP uses a separate 65 ms cadence; the 55 ms cue in `hud-boss.js` belongs to Boss HP intro fill.

Remaining Boss audio differences include source `boss:phase` roars delayed by 300 ms and dizzy-loop starts delayed by 350 ms after `boss:stun`; native phase changes currently play the phase cue without the roar, and stun starts the dizzy loop immediately. Native simulation also has no source `boss:foot` events, so Boss footsteps are absent. The Crablet spawn path does route each native spawn chitter separately, in addition to the move's hatch cue and delayed follow-up.

## Music transitions and remaining scope

Music changes between packaged tracks with the same BPM wait for the next source bar boundary, start the incoming track with an 8 ms fade, and fade the outgoing track over at most 250 ms. The native engine synthesizes the source riser live for the actual bar wait, using the source 2-second seeded white-noise buffer, exponential 400–7000 Hz band-pass sweep at Q 2.5, 220–1400 Hz saw sweep through a 3 kHz low-pass at Q 1, and the authored piecewise envelopes. It schedules the riser 20 ms after the request and ends it just before the downbeat. Different-tempo changes use a timed crossfade. Optional source recordings can be imported with `node tools/import-music.mjs splat-ref/songs`; the importer reads the source `songs/manifest.json`, copies supported WAV, FLAC or MP3 files under `assets/audio/songs/`, and writes `custom-music.tsv` rows as `track<TAB>gainDb<TAB>songs/<content-hash>.<extension>`. Native playback accepts recordings for `battle` and `battle_final`, applies the manifest gain, plays each recording once, and shuffles a per-track bag without repeating its last entry at bag boundaries. A missing or undecodable recording falls back to the packaged procedural track. Custom recordings have no source arrangement grid, so transitions to or from them use timed crossfades; `battle` begins another recording when one ends and `battle_final` remains one-shot. `GameAudio::Pause()` fades managed actor, device, Zone and Boss loops while leaving current music and the harbor wash running; the next update recreates state loops without replaying one-shot transition sounds. Boss phases select authored `boss`, `boss_2` and `boss_3` arrangements. The source `MusicEngine.setIntensity()` API has no native gameplay caller, so the native procedural tracks remain at the exported full-mix intensity of 1; no gameplay-driven stem changes are claimed. The full source SFX registry remains available in `AudioEngine` even when the native simulation has no matching event. Offline Zones now routes ownership, control, penalty, rotation, final, overtime and flood events, with a continuous parameter-driven native `zone_hum` synthesizer; see [the Zones contract](zones-source-contract.md). Result XP reveal now emits the registered `xp_tick` at the source 65 ms cadence while visible positive gain is counting up; the string-only UI sink uses steady native cue parameters instead of the source's per-progress pitch curve. Beam visuals also still need the firing actor or weapon identity before GameAudio can distinguish a charger shot from Wail audio.
